# Real-Time-Wireless-EV-Charger-with-Smart-Parking-System
Developed a dual-ESP32 smart wireless EV charger using ESP-NOW protocol. Steps 230V mains to 12V DC to drive an XKT-412 module (5V output). Integrates IR/ultrasonic sensors for coil alignment, an INA219 sensor, and a BMS for over-current/voltage fault protection. Sends real-time telemetry and charging status to users via a Telegram bot.
